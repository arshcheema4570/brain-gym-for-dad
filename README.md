# NeuroFlex — Offline Brain Training

A browser-based brain-training PWA for casual personal and family use. It includes a dashboard, five short game activities, progress views, and settings; progress is stored locally in the browser.

**Try it:** [Open NeuroFlex](https://arshcheema4570.github.io/brain-gym-for-dad/)

## Features

- Five mini-games: Memory Matrix, Speed Match, Lost in Migration, Color Match, and Chalkboard Challenge.
- Dashboard, daily workout flow, cognitive-domain summaries, score history, and streak/progress views.
- Sound controls and responsive layouts for phones, tablets, and desktop screens.
- Installable PWA with an offline app shell; no account is required. Saved progress remains in the browser on that device.

## Use and install

Open the deployed link in a modern browser. On a supported phone, choose **Install app** or **Add to Home Screen** from the browser menu. The app shell can launch offline after the first successful visit; browser storage can be cleared by the user or browser.

For local testing, serve the repository root over HTTP, for example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.

## Health and safety

This app is for entertainment and general mental activity. It is **not** a medical device, cognitive assessment, diagnosis, or treatment. Play at a comfortable pace and stop if you feel tired, frustrated, dizzy, or unwell. Consult a qualified health professional for medical concerns.
