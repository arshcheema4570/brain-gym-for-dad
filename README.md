# NeuroFlex — Dad’s Offline Brain Training

A standalone, single-file brain-training app for personal and family use. The app runs entirely in the browser and does not require an account, installation, or internet connection after the HTML file has loaded.

## Features

- Single-file offline HTML app
- Training dashboard and progress views
- Memory, speed, attention, flexibility, reasoning, math, and language activities
- Browser-local progress storage
- Responsive layout for phones, tablets, and computers
- No external JavaScript dependencies

## Use the app

Open [`index.html`](./index.html) in a modern browser. The public version is available here:

[Open NeuroFlex for Dad](https://raw.githack.com/arshcheema4570/neurospark-dad/main/index.html)

## Health and safety

This app is for entertainment and general mental activity. It is **not** a medical device, cognitive assessment, diagnosis, or treatment. Play at a comfortable pace and stop if you feel tired, frustrated, dizzy, or unwell. Consult a qualified health professional for medical concerns.
